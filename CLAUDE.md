## Development Commands

- **Start development server**: `pnpm dev` or `pnpm start`
- **Build for production**: `pnpm build`
- **Preview production build**: `pnpm preview`
- **Run tests**: `pnpm test` (uses Vitest)
- **Lint code**: `pnpm lint` (ESLint)
- **Type checking**: `pnpm type-check` (TypeScript compiler check)
- **Format code**: `pnpm prettier`
- **Astro type checking**: `pnpm astro-check`
- **Generate database migration**: `pnpm drizzle:migration:generate`
- **Apply database migrations to production D1**: `pnpm drizzle:migration:apply`
- **Deploy from a local build**: `pnpm build && pnpm deploy`
- **Create standard.site publication** (one-time setup): `pnpm standard-site:create-publication`
- **Publish a static HTML page to standard.site**: `pnpm standard-site:publish-page <file.html>`
- **Import a Goodreads library export**: `pnpm goodreads:import <export.csv>`

## Architecture Overview

This is a personal website built with **Astro** as the main framework, using **Preact** for interactive components and **Tailwind CSS** for styling. The site runs on **Cloudflare Workers** with a **D1** database.

### Key Technologies

- **Astro 7.x**: Static site generator with islands architecture. Markdown/MDX run through Astro 7's Sätteri processor with the mdast/hast plugins in `src/lib/markdown.mjs` and `src/lib/satteri/` (Sätteri plugins, not remark/rehype ones). Shiki highlights code blocks
- **Preact**: React alternative for interactive components (configured with React compatibility via @preact/compat)
- **Tailwind CSS**: Utility-first CSS framework with DaisyUI components
- **TypeScript**: Full TypeScript support throughout
- **Drizzle ORM**: Database ORM for SQLite (Cloudflare D1)
- **MDX**: Enhanced markdown with component support

### Project Structure

- `src/pages/`: Astro pages and API routes
- `src/components/`: Reusable UI components
- `src/layouts/`: Page layout templates
- `src/content/`: Content collections (blog posts, talks, resume experiences)
- `src/lib/`: Utility libraries and integrations (Last.fm, Goodreads, Bluesky, etc.)
- `src/lib/database/`: Database schema and migrations
- `src/styles/`: Global styles and theme configuration

### Content Management

- Uses Astro Content Collections for type-safe content management
- Blog posts, talks, and resume experiences are stored as Markdown/MDX files in `src/content/`
- Collections are defined in `src/content.config.ts`. `getCollection` returns entries sorted by ID, not loader order: use `getFeelings()` or sort by the `order` field (`byOrder`) from `src/lib/collections.ts` when order matters
- Dynamic data integrations with Last.fm, Goodreads, and other APIs

### Database

- Uses Cloudflare D1 (SQLite) with Drizzle ORM: the `DB` binding in the Worker, D1's HTTP API in builds and scripts. Write multiple rows with `db.batch`; D1 has no interactive transactions
- Database schema defined in `src/lib/database/schema.ts`
- Migrations are generated by `drizzle-kit` and applied with `pnpm drizzle:migration:apply` (wrangler)

### Sitemap

- Custom dynamic sitemap generated at `src/pages/sitemap.xml.ts` (not using `@astrojs/sitemap`)
- Includes `.astro` pages, `.html` pages, blog posts, and talks
- Last modified dates are derived from git commit history via `src/lib/lastModified.ts`

### Post Components

- MDX components available to blog posts and talks are registered in `src/components/Post/components.astro`
- `<Carousel />` wraps daisyUI's carousel for image galleries — see [`docs/post-carousel.md`](./docs/post-carousel.md)

### Resume

- `/resume/` is a Preact island (`src/components/Resume/`) rendered from a resume model in `src/lib/resume/`, which also produces `/resume.json` (JSON Resume). In-browser agents can tailor it to a job posting through WebMCP tools — see [`docs/resume-tailoring.md`](./docs/resume-tailoring.md)

### standard.site (ATProto) Publishing

- Publishes blog/link/feelings content (and hand-made static pages) to ATProto via `src/lib/standardSite.ts`, triggered in prerendered page renders and deduped through the `standard_site_documents` table — see [`docs/standard-site.md`](./docs/standard-site.md)

### Goodreads

- Homepage books come from Goodreads' public widgets, and every build saves them to the `goodreads_reviews` table. `pnpm goodreads:import <export.csv>` backfills reviews from a Goodreads export — see [`docs/goodreads.md`](./docs/goodreads.md)

### Deployment

- `@astrojs/cloudflare` adapter, Worker entry `src/worker.ts` (Astro plus the cron jobs), config in `wrangler.jsonc`
- Workers Builds runs `scripts/cloudflare/build.sh` and deploys: main to production, every other branch to a preview on its own copy of production D1. Playwright runs from GitHub Actions on each preview
- Server code reads secrets from `process.env`, not `import.meta.env`, which Vite writes into the bundle
- Secrets live encrypted in `.env.secrets` (dotenvx); `DOTENV_PRIVATE_KEY_SECRETS` decrypts them, and package scripts run through `dotenvx run`. Add one with `pnpm secrets:set KEY value`
- See [`docs/cloudflare.md`](./docs/cloudflare.md)
